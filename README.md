# Mini ATM — Modelado POO (Caso práctico 5.5, Deitel)

**Materia:** Programación Orientada a Objetos I — Semana 5, Día 1
**Tecnología:** C# · .NET 8 · Aplicación de consola

## Objetivo
Producir un modelo inicial orientado a objetos de un cajero automático (ATM) y demostrar
su viabilidad implementando dos clases en C# (`Cuenta` y `Transaccion`) usadas desde `Program.cs`.
